Install Ilium

A terminal workspace for coding agents. These installers download a matched client and server into your user directory; Rust and administrator access are not required.

Linux and macOS

curl --proto '=https' --tlsv1.2 -LsSf https://ilium-setup.pages.dev/install.sh | sh

Inspect the POSIX installer before running it. Requires a POSIX shell, curl, tar and an available SHA-256 tool. Linux requires the release's native runtime libraries.

Windows PowerShell

irm https://ilium-setup.pages.dev/install.ps1 | iex

Inspect the PowerShell installer before running it. Requires 64-bit Windows PowerShell 5.1 or current PowerShell. No execution-policy changes or elevation.

The public commands trust this HTTPS site and the release publisher. For a fixed version, download and inspect the script first, then use its version option. Verify release assets and attestations before running them.

Installation and upgrades leave running sessions alone. Agent CLIs are installed separately. Ilium's default automatic naming uses Kilo Gateway; review privacy settings before entering sensitive content.
