# Ilium v0.1.1-preview.4: Linux x86_64, Linux ARM64 and macOS Apple Silicon preview

This prerelease carries everything from `v0.1.1-linux.3` plus the first macOS Apple Silicon download. It does not become GitHub's latest release. `v0.1.1-linux.1`, `.2` and `.3` stay published and unchanged.

**Linux: the ten files of `v0.1.1-linux.3`, carried byte for byte.** Same names, sizes and SHA-256 as that release (x86_64: tar.gz, deb, rpm, AppImage, snap, flatpak; ARM64: tar.gz, deb, AppImage, flatpak). They were not rebuilt, so they still embed version `0.1.1-linux.3`. ARM64 rpm and Snap remain coming soon. x86_64 evidence is GitHub Actions runners and distribution containers; ARM64 evidence is an emulated QEMU guest only.

**macOS Apple Silicon (aarch64-apple-darwin): 1 of 4 formats, `ilium-macos-aarch64.tar.gz`.** Built, linted (Clippy), tested and audited natively on a GitHub Actions `macos-15` (Apple Silicon) runner, embedded version `0.1.1-preview.4`. ZIP, PKG and DMG are **coming soon**: their installed-package smoke test could not pass, because the animation helper sandbox (Seatbelt) is not qualified on macOS and the product disables animation packages there. The macOS tar.gz therefore runs without native animations.

**Signing:** the macOS binaries are unsigned and not notarized (no Apple credentials). After extracting, remove the quarantine flag (`xattr -dr com.apple.quarantine ilium-macos-aarch64`) or allow each binary in System Settings, Privacy & Security. macOS Intel is coming soon.

`SHA256SUMS` lists all eleven files; verify before installing. Plugins are an unsupported development preview.
