# Ilium v0.1.1-linux.3 — Linux x86_64 and ARM64 preview

This prerelease carries **both Linux architectures** from one source commit and one embedded version, `0.1.1-linux.3` (the deb and rpm versions read `0.1.1~linux.3`). It supersedes the separate `v0.1.1-linux.1` (x86_64) and `v0.1.1-linux.2` (ARM64) prereleases, which stay published and unchanged. It does not become GitHub's latest release.

**x86_64: 6 of 6 formats:** `ilium-linux-x86_64.tar.gz`, `.deb`, `.rpm`, `.AppImage`, `.snap` and `.flatpak`.

**ARM64 (aarch64): 4 of 6 formats:** `ilium-linux-aarch64.tar.gz`, `.deb`, `.AppImage` and `.flatpak`. The rpm and Snap ARM64 packages are **coming soon**: the rpm was only installed with `--nodeps`, and the Snap install did not complete in the emulated guest.

`SHA256SUMS` lists all ten files. Verify the checksum before installing.

**Evidence differs by architecture.** The x86_64 packages were built and installed on GitHub Actions runners and distribution containers. The ARM64 packages were cross-compiled and then installed and run only in an emulated ARM64 (QEMU) guest; they have not been tested on native ARM64 hardware.

Source: the release commit builds the x86_64 artifacts. The ARM64 binaries were built from its parent commit, which differs from the release commit only in test fixture files. macOS, Windows and the GitHub Packages bundle of the full v0.1.1 release are not part of this preview. Plugins are an unsupported development preview.

Keep the archive's client, server, animation helper, bundled animations and runtime libraries together. Native animations require Bubblewrap and cgroup-v2 delegation; see the [installation guide](https://github.com/arthurwolf/ilium/blob/v0.1.1-linux.3/src/docs/installation.md). Flatpak is experimental and grants host-command access.
