# Ilium v0.1.1-linux.1 — Linux x86_64 preview

This early prerelease is for Intel/AMD 64-bit Linux. It precedes the full cross-platform v0.1.1 release and does not become GitHub's latest release.

The intended downloads are `ilium-linux-x86_64.tar.gz`, `.deb`, `.rpm`, `.AppImage`, `.snap` and `.flatpak`, with the same basename, plus `SHA256SUMS`. Use the assets attached to this exact prerelease and verify their checksums before installing. Availability requires successful qualification, publication and public download verification; candidate workflow artifacts alone do not establish it.

See the [versioned README](https://github.com/arthurwolf/ilium/blob/v0.1.1-linux.1/README.md) and [installation guide](https://github.com/arthurwolf/ilium/blob/v0.1.1-linux.1/src/docs/installation.md). The default-branch README is updated separately when the feature branch is merged; this release does not merge that branch.

Linux ARM64, macOS Intel/Apple Silicon, Windows, hosted one-line installers, Pages installer delivery and the GitHub Packages bundle are **not ready for this preview**. Those platforms and channels await their separate qualification. Plugins are unsupported development preview code and are not intended for general use.

Keep the archive's client, server, animation helper, bundled animations and runtime libraries together. Native animations require Bubblewrap and cgroup-v2 delegation; see the installation guide. Flatpak is experimental and grants host-command access. Full-release installer lifecycle and cross-platform checks remain separate from this preview's package checks.
