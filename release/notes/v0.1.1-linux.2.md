# Ilium v0.1.1-linux.2 — Linux ARM64 preview

This early prerelease is for ARM64 (aarch64) Linux. It is published separately from `v0.1.1-linux.1` (Linux x86_64) because a published GitHub release is immutable and cannot gain assets. It does not become GitHub's latest release.

**4 of 6 formats are available:** `ilium-linux-aarch64.tar.gz`, `.deb`, `.AppImage` and `.flatpak`, plus `SHA256SUMS` listing exactly those four files. The rpm and Snap ARM64 packages are **coming soon**; they are not part of this release.

**Emulated verification only.** These four formats were installed and run in an emulated ARM64 (QEMU) guest. They have not been tested on native ARM64 hardware. Use the assets attached to this exact prerelease and verify their checksums before installing.

Linux x86_64 downloads live in [v0.1.1-linux.1](https://github.com/arthurwolf/ilium/releases/tag/v0.1.1-linux.1). This release is built from the same source plus the version bump only. macOS, Windows, hosted one-line installers and the GitHub Packages bundle are not ready for this preview. Plugins are unsupported development preview code.

Keep the archive's client, server, animation helper, bundled animations and runtime libraries together. Native animations require Bubblewrap and cgroup-v2 delegation; see the [installation guide](https://github.com/arthurwolf/ilium/blob/v0.1.1-linux.2/src/docs/installation.md). Flatpak is experimental and grants host-command access.
