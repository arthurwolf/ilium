# Ilium v0.1.1-preview.5: Linux x86_64, Linux ARM64 and macOS Apple Silicon (tar.gz, ZIP, PKG, DMG)

This prerelease carries everything from `v0.1.1-preview.4` plus the macOS Apple Silicon ZIP, PKG and DMG. It does not become GitHub's latest release. `v0.1.1-linux.1`, `.2`, `.3` and `v0.1.1-preview.4` stay published and unchanged.

**Linux: the ten files of `v0.1.1-linux.3`, carried byte for byte.** Same names, sizes and SHA-256; not rebuilt, so they still embed version `0.1.1-linux.3`. ARM64 rpm and Snap remain coming soon. x86_64 evidence is GitHub Actions runners and distribution containers; ARM64 evidence is an emulated QEMU guest only.

**macOS Apple Silicon (aarch64-apple-darwin): 4 of 4 formats** (`ilium-macos-aarch64.tar.gz`, `.zip`, `.pkg`, `.dmg`), embedded version `0.1.1-preview.5`. Built, linted, tested and audited natively on a GitHub Actions `macos-15` (Apple Silicon) runner. The ZIP, PKG and DMG were installed on that runner and passed the installed-package test: versions of client, server and helper, session create/list/kill lifecycle, and clean removal. Their contents are byte-identical to the tar.gz. The tar.gz is a fresh rebuild and is not byte-identical to the one in `v0.1.1-preview.4`.

**Animations are disabled on macOS.** The animation helper sandbox (Seatbelt) is not qualified, so the product refuses animation add-ons there with "macOS animation helper Seatbelt/resource isolation is not qualified; unverified packages are disabled". The macOS test asserts that refusal; it does not bypass it.

**Signing: unsigned and not notarized** (no Apple credentials). Gatekeeper will warn on the PKG and DMG. Right-click and choose Open, or allow it in System Settings, Privacy & Security, or run `xattr -dr com.apple.quarantine <file or extracted directory>`. macOS Intel is coming soon.

`SHA256SUMS` lists all fourteen files; verify before installing. Plugins are an unsupported development preview.
