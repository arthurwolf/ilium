# Ilium v0.1.1-preview.6: Linux x86_64, Linux ARM64, macOS Apple Silicon and Windows x86_64

This prerelease carries everything from `v0.1.1-preview.5` plus the Windows x86_64 setup EXE, MSI and ZIP. It does not become GitHub's latest release. `v0.1.1-linux.1`, `.2`, `.3`, `v0.1.1-preview.4` and `.5` stay published and unchanged.

**Linux: the ten files of `v0.1.1-linux.3`, carried byte for byte.** Same names, sizes and SHA-256; not rebuilt, so they still embed version `0.1.1-linux.3`. ARM64 rpm and Snap remain coming soon. x86_64 evidence is GitHub Actions runners and distribution containers; ARM64 evidence is an emulated QEMU guest only.

**macOS Apple Silicon: the four files of `v0.1.1-preview.5`, carried byte for byte** (`ilium-macos-aarch64.tar.gz`, `.zip`, `.pkg`, `.dmg`), still embedding version `0.1.1-preview.5`. Unsigned and not notarized; Gatekeeper warns. Animation add-on packages are disabled on macOS; the built-in background scenes still run. macOS Intel is coming soon.

**Windows x86_64 (x86_64-pc-windows-msvc): 3 of 3 formats** (`ilium-windows-x86_64-setup.exe`, `ilium-windows-x86_64.msi`, `ilium-windows-x86_64.zip`), embedded version `0.1.1-preview.6`. Built, tested and audited natively on a GitHub Actions `windows-2025` runner (GitHub Actions run 43566525456, source commit `d9acd19e`). The setup EXE and the MSI were each silently installed for the current user on that runner, run (versions of client, server and helper, plus a live session with a terminal pane), installed again over themselves, repaired and uninstalled, with the user `PATH` restored exactly; the setup EXE also passed ten `PATH` shapes (absent, empty, trailing `;`, expandable, borrowed entries). Both install the same files as the ZIP into `%LOCALAPPDATA%\Programs\ilium` without administrator rights.

**Animation add-on packages are disabled on Windows.** The built-in background scenes (Wave, Pipes, Stars and the others) still run. The add-on helper sandbox (AppContainer/Job) is not qualified, so the product refuses animation add-on packages there with "Windows animation helper AppContainer/Job isolation is not qualified; unverified packages are disabled". The Windows test asserts that refusal; it does not bypass it.

**Not available on Windows in this preview.** The shared resource queue (`ilium resource reserve` and the hardware reservation panel) needs Linux durable filesystem guarantees; on Windows it refuses with "resource queue requires a supported local durable filesystem" instead of granting reservations it cannot keep. Session statistics are not cached across restarts on Windows (the saved cache needs an owner-only file check that is not implemented there), so they are rescanned from the transcript. The tests for these Linux or Unix-only parts are marked as such and are replaced on Windows by tests that assert the refusal.

**Signing: the Windows files are unsigned** (no code-signing certificate). Microsoft Defender SmartScreen will warn "Windows protected your PC" on the setup EXE and the MSI: choose More info, then Run anyway, after checking the SHA-256. The PowerShell one-line installer does not install this prerelease; use the direct downloads. Windows ARM64 is not supported.

`SHA256SUMS` lists all seventeen files; verify before installing. Plugins are an unsupported development preview.
