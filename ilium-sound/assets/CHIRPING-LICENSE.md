# Chirping notification sound

`chirping.oga` is the unchanged GNOME Clocks chirping alarm, selected by the maintainer's Ilium session.

- Creator: **djfroyd**.
- Original recording: https://freesound.org/s/366490/.
- License: **Creative Commons Attribution 3.0 Unported**: https://creativecommons.org/licenses/by/3.0/.
- GNOME attribution: https://github.com/GNOME/gnome-clocks/blob/master/data/sounds/CREDITS.
- Imported from the installed Ubuntu `gnome-clocks` package at `/usr/share/sounds/gnome/default/alarms/chirping.oga`.
- No changes were made to the audio bytes.

The audio retains its own license; Ilium's source-code license does not replace it.

`chirping.wav` contains the same decoded audio in 16-bit PCM WAV format for the Windows system player. The original 44,100 Hz sample rate and stereo channels are retained. Format conversion is the only modification.
