### Changed
- Settings > Inference is now the Inference core plugin's page: provider, endpoints, credentials, model names, the restructure token budget and the provider test. Disabling the plugin removes the page.
- The Organization, Shared context and Project naming instruction inputs are edited only in Settings > LLM Instructions.

### Removed
- The built-in Settings > Inference tab, including its model catalog pickers and model refresh row; models are typed by name on the plugin page, and guided setup keeps its own catalog.
