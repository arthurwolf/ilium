### Added
- Plugin manual: two new core plugins, `ilium.core.attention` (the attention queue) and `ilium.core.resources` (shared resource queues and `ilium resource`), with their pages, requirements PRM-401 to PRM-413 and PRM-451 to PRM-465, and skeleton crates under `plugins/core`. The core set is now 32 plugins with 70 extension points.
- Plugin manual: requirements PRM-501 to PRM-517 and feature rows F-117 to F-126 for custom status icons, `ilium close-pane`, `ilium ctl`, the icon picker, the location picker, the provider proxy database, worktree custody and setup, and cache-wait observation.

### Changed
- Plugin manual: `ilium new-pane` is owned by the Fleet plugin everywhere; the kernel-and-boot page no longer lists it as a kernel command.
