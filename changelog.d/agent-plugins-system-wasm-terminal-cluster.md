### Changed

- The pane title no longer gets a `[done]` prefix when an agent finishes a turn. The Agent Detection plugin's completed-turn mark shows it instead.
- Screen transfer moved into the Terminal plugin. The arrow controls on split separators are gone; right-click a terminal and choose **Paste screen into another pane** (a list asks when the split view has several other terminals). With the Terminal plugin off, the entry is absent.
