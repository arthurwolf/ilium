### Changed
- Fourteen quiet scenes are now scenes of the Scenes plugin instead of built-in code: Northern lights, Pollen in a sunbeam, Fireflies, Window sunlight, Distant lighthouse, Paper-fold trace, Prime constellations, Turning wallpaper, Unfinished circle, Threads through a needle, Crop circles, Delayed reflection, Almost touching and Hidden wheel. A saved animation of one of these (`aurora`, `pollen`, ...) opens the Plugin scene animation. Their controls are unchanged. The former Northern lights black backdrop is gone: the scene is composited like every other plugin scene. Disabling the Scenes plugin removes them from the list.
- The manifest accepts up to 256 scenes per plugin (was 16).
- Box machine, Dithr patterns, Galactic empires and Solar system are now scenes of the Scenes plugin too, with their controls and tests. A saved animation of one of these (`box_machine`, `dithr_patterns`, `galactic_empires`, `solar_system`) opens the Plugin scene animation. Dithr patterns lost its optional GPU renderer (the Render backend row is gone) and three controls were renamed so they do not clash with the shared look: Dither is now Grain, Dither amount is Grain amount and Contrast is Dot level; saved values of the old names are not carried over.
