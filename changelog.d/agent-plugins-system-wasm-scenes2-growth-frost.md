### Changed
- The Growth, Frost, Embroidery orbit and Ink that hesitates background scenes now run from the Scenes plugin. Disabling the plugin removes them, and saved selections of these scenes load as plugin scenes.
- Plugin scenes can read the pointer position and the foreground-text occupancy mask, so Growth and character-mode Frost still react to the pointer and to terminal text.
- Vector TD, the self-playing tower defense, is now a scene of the Scenes plugin with the same controls; a saved `vector_td` selection opens the Plugin scene animation.
