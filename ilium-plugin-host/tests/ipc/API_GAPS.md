# API gaps of ilium-plugin-host/tests/ipc (lane host-ipc, part 1)

The host has no edge to ilium-ipc (test plan 1.2), so the server-side rules of reference-host-ipc.md are tested against a new pure module `ilium_plugin_host::ipc` and a harness `ilium_plugin_host::testing::ipc_harness` (feature `testing`). Neither exists in the skeleton.

## Module `ilium_plugin_host::ipc` (pure, no I/O)
- ilium-plugin-host: `pub const DEDUP_WINDOW_MS: u64 = 600_000; pub const OUTCOME_GRACE_MS: u64 = 30_000; pub const OUTCOME_RECORD_LIMIT: usize = 1_024; pub const DETACHED_QUEUE_LIMIT: usize = 256; pub const PTY_FRAMES_PER_PLUGIN_ENVELOPE: u32 = 8; pub const PLUGIN_QUEUE_MAX_BYTES: usize = 4*1024*1024; pub const PLUGIN_QUEUE_MAX_RECORDS: usize = 4_096; pub const CLIENT_TOO_SLOW_BYTES: usize = 16*1024*1024; pub const ENVELOPE_MAX_BYTES: usize = 17*1024*1024; pub const EXIT_CODE_PROTOCOL_MISMATCH: i32 = 76;` [HST-113, 116, 119, 120, 121, 122, 125, 104] numbers copied from the manual.
- ilium-plugin-host: `#[derive(Debug, Clone, PartialEq, Eq)] pub struct IpcFault { .. }` with `pub fn code(&self) -> &str` (`ipc.sequence-gap`, `ipc.payload-too-large`, `ipc.client-too-slow`, `ipc.protocol-mismatch`) and `pub fn completion_outcome(&self) -> Option<&'static str>` (`Some("failed(too-large)")` for payload-too-large, else None). [HST-102, 124]
- ilium-plugin-host: `pub enum PayloadKind { MessageBody, TopicPayload, UiTree, UiTreeT1, SurfaceWrite, Envelope, ContributionDelta }` and `pub fn check_payload(kind: PayloadKind, len: usize) -> Result<(), IpcFault>` (caps 1 MiB, 64 KiB, 1 MiB, 4 MiB, 16 MiB, 17 MiB, 4 MiB). [HST-109, 124]
- ilium-plugin-host: `pub fn encode_checked<F: FnOnce() -> Vec<u8>>(kind: PayloadKind, declared_len: usize, encode: F) -> Result<Vec<u8>, IpcFault>`; must not call `encode` when over the cap. [HST-124]
- ilium-plugin-host: `pub struct ReceiverConnection` with `pub fn new() -> Self`, `pub fn on_envelope(&mut self, seq: u64, encoded_len: usize) -> Result<(), IpcFault>`, `pub fn is_open(&self) -> bool`, `pub fn closed_with(&self) -> Option<String>`. Expects seq 1 first, then +1; a gap or oversize envelope closes. [HST-102, 125]
- ilium-plugin-host: `pub struct ForwardedDedup` (`new()`, `admit(&mut self, plugin: &str, client_id: &str, dedup_key: &str, now_ms: u64) -> DedupVerdict`), `pub enum DedupVerdict { Fresh, Duplicate }`. A key is free at exactly `now_ms - accepted_ms == 600_000`. [HST-113]
- ilium-plugin-host: `pub struct OutcomeStore` (`new()`, `record(&mut self, client_id: &str, seq: u64, outcome: &str, now_ms: u64)`, `on_disconnect(&mut self, client_id: &str, now_ms: u64)`, `replay(&mut self, client_id: &str, last_seen_seq: u64, now_ms: u64) -> Vec<StoredOutcome>`, `record_count(&mut self, client_id: &str, now_ms: u64) -> usize`) and `pub struct StoredOutcome { pub seq: u64, pub outcome: String }`. Oldest records are dropped beyond 1,024 per client id. [HST-116, 117]
- ilium-plugin-host: `pub struct DetachedQueue` (`new()`, `push(&mut self, dedup_key: &str) -> QueueVerdict`, `len(&self) -> usize`, `on_client_exit(&mut self) -> Vec<String>` returning the cancelled keys in queue order) and `pub enum QueueVerdict { Queued, RefusedBusy }`. [HST-119]
- ilium-plugin-host: `pub struct WriterQueues` (`new()`, `push_pty_frame(&mut self, id: u32)`, `push_plugin(&mut self, record: PluginRecord) -> PushOutcome`, `next(&mut self) -> Option<Written>`, `resync_flagged(&self) -> bool`, `plugin_queued_bytes(&self) -> usize`, `plugin_queued_records(&self) -> usize`), `pub struct PluginRecord { pub id: u32, pub bytes: usize, pub coalesce_key: Option<String> }`, `pub enum Written { Pty(u32), Plugin(u32) }`, `pub enum PushOutcome { Queued, Merged, ResyncFlagged, Disconnect(IpcFault) }`. A same-key coalescable record replaces the queued one (Merged). A record that cannot be merged and exceeds 4 MiB or 4,096 records sets the resync flag (ResyncFlagged) but still counts as queued bytes, so the 16 MiB hard cap can be reached. [HST-120, 121, 122, 123]

## Harness `ilium_plugin_host::testing::ipc_harness` (feature `testing`)
- ilium-plugin-host: `pub struct ConnId` (Copy, Debug, PartialEq) and `pub struct IpcHarness` with `new() -> Self`, `install_server_plugin(&mut self, id: &str, version: &str, content_hash: [u8; 32])`, `grant(&mut self, plugin: &str, grant: &str)`, `revoke(&mut self, plugin: &str, grant: &str)`, `matching_hello(&self) -> HelloSpec`, `connect(&mut self, client_id: &str, interactive: bool, hello: HelloSpec) -> ConnId`, `reattach(&mut self, client_id: &str, last_seen_seq: u64, hello: HelloSpec) -> ConnId`, `disconnect(&mut self, conn: ConnId)`, `advance(&mut self, by: std::time::Duration)`, `pump(&mut self, max_rounds: u32)`. In-process server plus client halves around a FakeKernel; grant `panes.create` gates intent `create-pane` (outcome `ok-node`). [HST-100..125]
- ilium-plugin-host: `HelloSpec { pub plugin_protocol: u16, pub contract: String, pub installed: Vec<InstalledSpec> }`, `InstalledSpec { pub id: String, pub version: String, pub content_hash: [u8; 32] }`; `matching_hello` returns protocol 1, contract "0.1.0" and the server's plugin set.
