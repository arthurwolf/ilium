# API gaps of ilium-plugin-host/tests/imports_core (lane imports-core, part 1)

The skeleton host-import traits (`HostLog`, `HostClock`, `HostCodec`, `HostFs`, `HostHttp`, `HostJobs`, `HostJournal`, `HostPanes`, `HostProcess`, `HostSettings`) are unit structs without context, so a test cannot give a plugin a manifest, grants, a project directory, a clock or limits. The tests therefore use one harness, `ilium_plugin_host::testing::imports_fixture` (feature `testing`). None of it exists in the skeleton. Every item is needed by a test in this folder.

## Builder `ImportsFixtureBuilder` (from `ImportsFixture::builder()`)
- ilium-plugin-host: `pub fn tier(self, tier: ilium_plugin_api::Tier) -> Self`, `side(self, side: ilium_plugin_api::side::Side) -> Self`, `grants(self, grants: &[&str]) -> Self`, `manifest_json(self, json: &str) -> Self` (installs the plugin `test.imports` unless the JSON sets another id; the default is a minimal manifest), `project_root(self, root: &std::path::Path) -> Self` (backs the `project` fs scope), `limit(self, name: &str, value: u64) -> Self` (names `fs_read_all_mib`, `fs_write_mib`, `journal_entries`), `build(self) -> ImportsFixture`. [SET-*, all WIT ids]
- ilium-plugin-host: `also_install(self, manifest_json: &str) -> Self` installs a second plugin (for the `settings.read-all`, `settings.write-all` and `list-settings` tests). [WIT:ilium:host/settings.get-plugin-json, set-plugin-json, list-settings]
- ilium-plugin-host: `settings_validate(self, f: Box<dyn FnMut(&str, &str) -> Result<(), Vec<FieldError>>>) -> Self` (patch JSON, merged JSON) and `settings_validate_latency(self, d: Duration) -> Self` (the fake export answers after `d` of virtual time). [SET-020..024, WIT:ilium:exports/settings-validate.settings-validate]
- ilium-plugin-host: `job_runner(self, f: Box<dyn FnMut(&str, &[u8]) -> Result<Vec<u8>, PluginError>>) -> Self` (the fake `job-runner.run` export). [WIT:ilium:exports/job-runner.run]
- ilium-plugin-host: `websocket_feature(self, on: bool) -> Self`. [WIT:ilium:host/http.open-websocket]
