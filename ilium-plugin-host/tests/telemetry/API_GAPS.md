# API gaps: telemetry lane (ilium-plugin-host/tests/telemetry)

Tests use these items; the skeleton lacks them. No new dev-dependencies are needed (proptest, tempfile, serde_json exist).

- ilium-plugin-host `telemetry::SideTelemetry`: `new() -> SideTelemetry` with `record_call(CallClass, Duration, Duration, u64)`, `record_breach(CallClass, BreachKind, u64)`, `record_trap(&str, u64)`, `record_queue_depth(u64, u64)`, `record_event_dropped(&str, u64, u64)`, `record_event_coalesced(&str, u64, u64)`, `record_quota_rejection(u64)`, `record_rate_limited(&str, u64)`, `record_cpu_ms(u64, u64)`, `record_memory(u64, u64)`, `record_helper_round_trip(Duration, u64)`, `record_render(&str, Duration, u64)`, `record_restart(&str, u64)`, `record_failure(&str, u64)`, `snapshot(u64) -> Vec<HourBucket>`, `memory_bytes() -> usize`, `end_instance(u64) -> Option<String>`; HST-350..360. Counters, histograms and hour buckets do not exist.
