## User and administrator requirements

This page collects every requirement of the user and administrator documentation, one row for each id. Each requirement has a test. The ids are written `[USR-nnn]` where the page states the rule, and each row here links to that page.

Contract version: `ilium:plugin@0.1.0`. The platform is not implemented yet, so every row describes behaviour that the platform must have.

### You will need

- The [Plugins for users](/pages/user-plugins-overview/) page, for the words used here.
- The [Administration guide](/pages/guide-administration/) for the policy rows.

### First run and guided setup (USR-35x)

The guided setup is the flow started on first run or by `ilium --onboarding`. The [Settings plugin](/pages/core-plugin-settings/) owns the flow, and each step is a section contributed through the `onboarding-steps` extension point by the plugin that the step configures. A step has an `id`, a `title` and an `order`. The rows below are new: their ids are not yet in the numbered rows above, and they relate to USR-014 (first-start prompt of a bundled plugin), USR-305 (screen reader mode) and USR-316 (pseudo-locale `en-XA`) and USR-951 (release walkthrough at 48 columns).
