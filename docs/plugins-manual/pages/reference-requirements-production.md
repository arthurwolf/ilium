## Requirements for production operation

This page lists every requirement of the production pages (installation, publishing, security containment, compatibility, operations, performance, accessibility and author onboarding), one row each. The statement is the owner bullet word for word. Change the bullet first, then copy it here.

| Id | Statement | Page | Testable how |

| INS-001 | `--yes` MUST NOT accept a grant with the risk level `high`, a new `replaces` entry, or a key that is not yet trusted. Only `--grant <grant>` accepts a high-risk grant and only `--trust <key_id>` trusts a key. Test: install a package with one high-risk grant and an unknown signing key using `--yes`, then assert that the install exits 1 with `install.review-required` and that `ilium plugin list` shows no new plugin. | [install-flag-matrix](/pages/install-flag-matrix/) | install a package with one high-risk grant and an unknown signing key using `--yes`, then assert that the install exits 1 with `install.review-required` and that `ilium plugin list` shows no new plugin. |
