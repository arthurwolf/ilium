## Requirements: manifest and package

This page lists every requirement id of the form `PKG-nnn`. The ids cover the manifest, the package format, signing and trust, the registry, install and update, dependency resolution, the distribution commands, administration, publishing and the plugin store. The table is generated by a script from the definitions on the other pages. Do not edit it by hand. Each row gives the id, the statement, the page that defines it and how a test checks it.

Id ranges: 001 to 099 manifest, 100 to 199 package format, 200 to 259 signing and trust, 260 to 305 install and update, 310 to 360 dependency resolution, 361 to 422 registry, 423 to 446 distribution commands, 460 to 489 administration, 490 to 529 publishing, 530 to 559 plugin store, 560 to 589 manifest schema, 650 to 659 package lifecycle additions (signature document, registry signing and dependency cycles).
