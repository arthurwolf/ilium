## Security and policy requirements

Every normative statement of the security pages with its id. The columns are: id, the statement (shortened), the page that explains it, and how to test it. A statement uses MUST, SHOULD or MAY as in RFC 2119 on its page; this table repeats only the subject. Rows whose test column names a fixture refer to the suite in [Security testing](/pages/reference-security-testing/).

### You will need

- The pages listed in the third column.
