## Open security decisions

Every security value that a page marks as `proposed, owner to confirm` appears once in this register. Each row names the requirement ID, the proposed text, the page that owns the requirement, and the owner decision still needed. The owner column reads `Not recorded` until the project owner records a decision, and the due release is the first public release.

A release MUST NOT ship while a row has no confirmed value, and the release checklist lists every open row. When the owner confirms a value, change the owner page first, remove the words `proposed, owner to confirm` there, and then remove or update the row here.
