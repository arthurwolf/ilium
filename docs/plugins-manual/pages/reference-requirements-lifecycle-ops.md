## Requirements, lifecycle and operations

This page lists every normative statement of the lifecycle and operations lane, one row each, with its test. The ids have the form `LIF-nnn`. Contract version: `ilium:plugin@0.1.0`.

### How to read the rows

- MUST and MUST NOT mark a rule a host has to meet. SHOULD marks a rule to follow unless there is a stated reason. MAY marks a choice.
- An id is never reused. A removed rule keeps its number and is marked removed.
- Each row links to the page that explains the rule. The page is the source. This table is built from it.
- The platform is not implemented. A test is a description of how to check, written for the fake host and for a real host.
