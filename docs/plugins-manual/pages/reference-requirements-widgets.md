## Requirements for widgets

Normative behaviour of the ui-tree, the 51 widgets, keys, actions, popups, focus and render-time caps.

The rows follow the format and the observation channels of the [requirements index](/pages/reference-requirements/). The id prefix is `WID`.

| Id | Requirement | Source | Observable test |
|---|---|---|---|
| [WID-001] | The widget catalogue MUST hold 51 widgets in 7 families. A plugin MUST describe a view only with these widgets. | [the seven families](/pages/widgets-index/#the-seven-families) | (install-error) run the check tool over the widget pages -> 51 distinct widget names. |
| [WID-002] | A ui-tree MUST be a flat list of nodes whose root is node 0. Every child index MUST be in range and greater than its parent index, and a node MUST have at most one parent. Any violation, including a cycle, MUST trap with ui.invalid-tree. | [the ui tree](/pages/ui-model/#the-ui-tree) | (trap) return a node whose child index is 99 of 5 nodes -> trap ui.invalid-tree. |
| [WID-003] | A key MUST be unique across the whole view, not only among siblings. A duplicate key, or two items in one widget with the same item id, MUST trap with ui.duplicate-key. | [the ui tree](/pages/ui-model/#the-ui-tree) | (trap) two nodes with key "save" in different branches -> trap ui.duplicate-key. |
| [WID-004] | A tree MUST NOT hold more nodes than the effective ui_tree_nodes limit, 4,096 by default. | [errors and edge cases](/pages/layout/#errors-and-edge-cases) | (trap) 4,097 nodes -> trap. |
| [WID-005] | A layout MUST have as many constraints as children. A mismatch MUST trap. | [errors and edge cases](/pages/layout/#errors-and-edge-cases) | (trap) layout with 3 children and 2 constraints -> trap. |
| [WID-006] | A layout percentage above 100 MUST be clamped to 100. | [errors and edge cases](/pages/layout/#errors-and-edge-cases) | (screen-text) percentage 150 in a 40 column row -> the child gets 40 columns. |
| [WID-007] | Fixed, min, max, percentage, ratio and fill constraints MUST be solved in the order given on the layout page, and the cells MUST sum to the area width. | [how the solver divides one row](/pages/layout/#how-the-solver-divides-one-row) | (screen-text) fixed 10 and fill in 40 columns -> 10 and 30. |
| [WID-008] | A widget action MUST reach the plugin as a ui-action event carrying the node key and the action value. | [actions back to the plugin](/pages/ui-model/#actions-back-to-the-plugin) | (event-delivery) click a button with key "save" -> ui-action key "save". |
| [WID-009] | Host-owned state (scroll offset, text cursor, selected tab) MUST survive a re-render when the key is unchanged. | [keys and host owned state](/pages/ui-model/#keys-and-host-owned-state) | (screen-text) scroll a list, re-render with the same key -> the offset stays. |
| [WID-010] | A node with pointer-events and without focusable MUST send no pointer actions. | [edge cases and errors](/pages/ui-model/#edge-cases-and-errors) | (event-delivery) click such a node -> no ui-action. |
| [WID-011] | Escape MUST be reserved by the host and resolved in this order: a capturing key-capture, a text selection, the topmost popup, then a modal panel. A modal popup MUST send closed. | [Escape](/pages/ui-model/#escape) | (event-delivery) press Escape in an open modal popup -> closed arrives and the popup is gone. |
| [WID-012] | More than 4 open popups in one view MUST make open-popup fail with quota-exceeded. | [edge cases and errors](/pages/ui-model/#edge-cases-and-errors) | (sync-return) open a fifth popup -> err quota-exceeded. |
| [WID-013] | A code-view on a buffer the plugin did not create MUST need editor.read, and a terminal-view MUST need terminal.read-screen. Without the grant the widget MUST draw an empty frame with the text "not permitted". | [edge cases and errors](/pages/ui-model/#edge-cases-and-errors) | (screen-text) terminal-view without the grant -> frame with "not permitted". |
| [WID-014] | views.render has no result type. A render that breaks a limit (ui.too-large, ui.too-deep, ui.widget-not-allowed, ui.invalid-tree, ui.duplicate-key) MUST trap the render call with trap.invalid-ui-tree and the matching ui.* code as its detail reason, an item-count overflow trapping with ui.invalid-tree (WID-020). The host MUST log one error with the widget path, keep the last good tree on screen marked stale and count one failure. | [edge cases and errors](/pages/ui-model/#edge-cases-and-errors) | (trap) check-list with 257 items -> trap, the previous tree stays, and one log line with the widget path. |
| [WID-015] | A tooltip longer than 200 Unicode scalar values MUST be cut at 199 and end with the ellipsis. It MUST NOT be an error. | [edge cases and errors](/pages/ui-model/#edge-cases-and-errors) | (screen-text) tooltip of 300 characters -> 200 cells ending in the ellipsis. |
| [WID-016] | In a settings view, a widget outside the allowed subset MUST trap the render call with ui.widget-not-allowed: the host logs one error with the widget path, keeps the last good tree and counts one failure. | [settings views](/pages/ui-model/#settings-views) | (trap) render a terminal-view in a settings view -> trap ui.widget-not-allowed, previous tree stays. |
| [WID-020] | check-list MUST accept at most 256 items and list-editor at most 64 (1,024 with limits_tier first-party). | [requestable limits](/pages/reference-errors-and-limits/#requestable-limits) | (trap) list-editor with 65 items as T2 -> trap with ui.invalid-tree, the previous tree stays, one error logged. |
| [WID-021] | meter MUST have at most 8 segments, minimap at most 4,096 marks per layer, and spinner at most 16 custom frames. | [requestable limits](/pages/reference-errors-and-limits/#requestable-limits) | (trap) meter with 9 segments -> trap with ui.invalid-tree logged. |
| [WID-022] | The calendar widget (unstable) MUST show one month with Monday first, and MUST need the unstable list to include it. | [calendar](/pages/widgets-data-display/#calendar) | (install-error) use calendar without listing it in unstable -> manifest.unstable-missing. |
| [WID-023] | A ratio below 0 or above 1 MUST be clamped to the range and NaN MUST draw as 0. A progress-row percent above 100 MUST be clamped to 100. | [edge cases and errors](/pages/widgets-data-display/#edge-cases-and-errors) | (screen-text) gauge ratio 1.5 -> drawn full. NaN -> drawn empty. |
| [WID-024] | chart MUST draw Braille where the terminal supports it and a text-line fallback otherwise. | [chart](/pages/widgets-data-display/#chart) | (screen-text) same chart at two capability levels -> Braille and text-line renders. |
| [WID-025] | Text widgets MUST wrap at the area width. paragraph spans that carry an action MUST send it when clicked. | [widgets text](/pages/widgets-text/) | (event-delivery) click an action span -> ui-action with that action. |
| [WID-026] | Input widgets MUST send their change per the debounce rule: toggles, choices and confirmations at once, typed text after the debounce. A text-area with debounce-ms unset MUST wait 600 ms up to 10,000 bytes of text and 1,000 ms above, re-evaluated at each keystroke. An explicit debounce-ms MUST win. This rule covers the `changed` event of a text-area widget in a plugin view only; a text-area row of a settings tab is written 600 ms after the last keystroke while its text is at most 10,000 bytes, and 1 s above that (SET-023). | [when the plugin hears about a change](/pages/widgets-input/) | (event-delivery) type 10,001 bytes into a text-area -> changed after 1,000 ms; with debounce-ms 200 -> after 200 ms. |
| [WID-027] | The ui-action event MUST carry five fields, and action-id MUST be a copy of key in 0.1.0. | [keys are action ids](/pages/widgets-input/#keys-are-action-ids) | (event-delivery) click toggle key "dark" -> ui-action key "dark" and action-id "dark". |
| [WID-028] | An image whose asset is missing, corrupt, unsupported or over 16 MiB MUST draw an empty frame with the text "image not available". A code-view or terminal-view that names a missing buffer or pane MUST draw an empty frame with the text "not found". | [widgets media and embedded](/pages/widgets-media-and-embedded/) | (screen-text) image with a missing asset -> frame with "image not available". terminal-view of a closed pane -> "not found". |
| [WID-017] | A tree deeper than 32 levels, counting the root as level 1, MUST trap with ui.too-deep. | [the ui tree](/pages/ui-model/#the-ui-tree) | (trap) a chain of 33 nested blocks -> trap ui.too-deep. |
| [WID-018] | Tab MUST visit focusable nodes with tab-index 1 or more in ascending order, then nodes with none or 0 in tree pre-order, and MUST skip negative values and nodes with disabled-reason. | [focus order](/pages/ui-model/#focus-order) | (event-delivery) tab-index 2 then 1 then none -> focus visits 1, 2, none. |
| [WID-019] | Cell width MUST follow one rule for every widget: the host width of a string in cells, with wide glyphs as 2 and combining marks as 0. | [cell width](/pages/ui-model/#cell-width) | (screen-text) a label of 3 wide glyphs in 6 cells -> fits without cut. |
| [WID-029] | A popup or dialog node MUST take no space in its parent layout. A popup id MUST be the node key and unique across a plugin's open views, and close-popup on an unopened id MUST be a no-op that returns ok. | [popups and anchors](/pages/ui-model/#popups-and-anchors) | (screen-text) a length(0) slot holding a popup leaves the sibling area unchanged. |
| [WID-030] | A theme change MUST repaint the last tree of every open view, deliver theme-changed and trigger exactly one views.render per open view. | [rendering triggers](/pages/reference-host-rendering/) | (event-delivery) switch theme -> one theme-changed and one render. |
