## Requirements for author guides

This page lists every requirement with the prefix `AUT`. They come from the author guides (patterns, performance, compatibility, publishing, quality, accessibility, internationalisation, porting and troubleshooting) and from the pages those guides amend. The table is generated from the pages by a script, so each row repeats the sentence of its page.

Rules for ids:

- An id is never reused and never renumbered, even when its requirement is removed.
- A requirement that is removed stays in the table with the statement `withdrawn`, so that a test that cites the id can still be traced.
- Ranges: 0nn patterns, 1nn performance and limits, 2nn compatibility, 3nn publishing, 4nn quality, 5nn accessibility, 6nn internationalisation, 7nn porting, 8nn troubleshooting and debugging.
- A statement uses MUST for a rule a tool or test can check, SHOULD for a strong recommendation, and MAY for an allowed choice.

The column "Testable how" says what kind of check settles the requirement. Where the check is a review, no automatic test is possible.
