# Keys

Ilium is driven by a prefix key followed by a second key. Press the prefix, release it,
then press the key of the command.

- The key reference lists every command with the key it is bound to.
- Settings, tab Keyboard, changes the prefix, picks a preset and rebinds single commands.
- A plugin adds its own commands to the reference; they disappear when the plugin is
  disabled.

A key that is bound twice is shown as a conflict in Settings, and the first binding wins
until you resolve it.
