# API gaps for the diagnostics feature tests

- ilium.core.diagnostics manifest and manual page: service `ilium.core.diagnostics/agent-debug` (JSON request with `method`, JSON reply) is not in the manifest or on the page. Methods assumed by agent_debug_*.rs: append, merge, entries, snapshot, restore, retain_from, enable, observe, replay, remove, payload, report, save, file_mode, link, read_file, view, sanitize, format_timestamp, record, open, save_prompt, save_log, make_directory, scroll, mirror_snapshot, mirror_append, mirror, pane_closed. Needed for F-032 and the PORT ids of ilium-agent-debug, ilium-client and ilium-server. Wire shapes are in the tests; the page must define them.
- ilium.core.diagnostics manifest: grant for pane debug data (the tests assume it is covered by `panes.read`) and the setting `agent_debug_menu_enabled` are not listed. Needed for F-032.
- ilium-plugin-testkit `FakeSession`: `pub fn contribute(&mut self, plugin: &str, point: &str, id: &str, priority: i32, entry: serde_json::Value)`, adds an extension contribution to a point (EXT-054, SEC-249, report sections).
- ilium-plugin-testkit `FakeSession`: `pub fn stub_service(&mut self, plugin: &str, service: &str, method: &str, reply: Result<String, PluginError>)`, a service of a stub plugin that answers a text (report sections).
- ilium-plugin-testkit `FakeSession`: `pub fn stall_service(&mut self, plugin: &str, service: &str, method: &str)`, a service that never answers, so the 2000 ms section deadline can be tested.
- ilium-plugin-testkit `FakeSession`: `pub fn observe_hook(&mut self, plugin: &str, point: &str, priority: i32)`, registers a recording observer on a hook point (EXT-054).
- ilium-plugin-testkit `FakeSession`: `pub fn hook_chains(&mut self, plugin: &str, point: &str) -> Vec<Vec<serde_json::Value>>`, the chains an observer received, one list of payloads per chain (EXT-054).
- ilium-plugin-testkit `FakeSession`: `pub fn observer_logs(&mut self, plugin: &str, point: &str, level: &str, message: &str)` and `pub fn observer_fails(&mut self, plugin: &str, point: &str)`, make an observer write a log record or fail during its call (EXT-054 no feedback loop).
- ilium-plugin-testkit `FakeSession`: `pub fn plugin(&mut self, id: &str) -> &mut FakeHost` returning the server-side host of any installed plugin (LIF-138 degrade a plugin).
- ilium-plugin-testkit `FakeSession::pump`: `pub fn pump(&mut self) -> Result<(), HarnessError>` that settles deferred service replies and fs-changed deliveries of all hosts.
- ilium-plugin-sdk-core `ViewTarget`: no `Popup`-for-dialog id convention is documented; tests use `ViewTarget::Popup("attach-log")` for the attach dialog and `ViewTarget::Popup("report-preview")` for the report preview, and `ViewTarget::Panel("warnings")` for the warnings list. Needed for COR-050 renders.
- ilium-plugin-testkit `FakeFs`: the client fake file system must accept the shorthand `"path:/tmp/dest/copy.txt"` for a write and a read, and `fs.pick` results (`send_action` with key `pick`) for the attach dialog.
- ilium-plugin-testkit `FakeSession`: `pub fn client(&mut self, id: &str) -> &mut FakeHost` and `pub fn server(&mut self, id: &str) -> &mut FakeHost` are assumed as in the sibling lanes.
- dev-dependency: `proptest` (agent_debug_history.rs) and `serde_json` in plugins/core/diagnostics/Cargo.toml.
- Not ported, no testable surface on the plugin API: ilium-server/tests/debug_logging_process.rs::detached_server_process_logs_major_ipc_actions_and_errors, ilium-server/tests/smoke.rs::successful_resize_records_its_typed_client_cause_in_the_debug_journal, ilium/tests/pty_tui_smoke.rs::agent_debug_log_filters_panel_resizes_and_saves_the_active_view, ilium-client/src/debug_logging.rs::logging_transition_child and ::ordered_transitions_are_bounded_and_server_sync_never_becomes_client_origin (process-level, global logger singleton).
