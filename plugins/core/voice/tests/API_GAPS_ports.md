# API gaps of the voice port tests

- crate `ilium-plugin-testkit`, `FakeHost::client_requests().sent()` returning items with `client`, `kind`, `request`, `payload_json`, `timeout_ms`; and `.answer(request, Ok(line))` (F-052): the relay twins offer to several attached clients and answer them one by one. Already listed in `API_GAPS.md` of the features part.
- crate `ilium-plugin-testkit`, `FakeHost::kernel_settings("voice-control").set(key, value) -> Result<_, _>` rejecting `output_volume_percent` above 100 (F-054): the volume-101 twin needs the page's range validation to run in the fake kernel.
- crate `ilium-plugin-testkit`, `host.cli().invoke(args, stdin)` called twice before `settle()` giving distinct request ids (F-052): needed by the in-flight request-id twin.
- crate `ilium-plugin-testkit`, `FakeHost::realtime(&mut self) -> &mut FakeRealtime` (F-050, F-051): the fake Realtime conversation. Needs `tools() -> Vec<ToolDef { name: String, parameters_json: String }>`, `call_tool(&mut self, name: &str, args_json: &str) -> Result<String, PluginError>`, `call_tool_with_id(&mut self, call_id: &str, name: &str, args_json: &str) -> Result<String, PluginError>`, `executions(&self, call_id: &str) -> u32`, `system_prompt(&self) -> String`, `typed_text(&self) -> Vec<String>`, `tool_calls(&self) -> Vec<String>`, `set_active_agent(&mut self, class: &str)`, `target_context(&self) -> Option<String>`, `last_submit_enter(&self) -> Option<bool>`, `pending_confirmation(&self) -> Option<String>`, `answer_confirmation(&mut self, answer: &str) -> String`. The tool names (`ilium_stop_voice`, `ilium_dictate_text`, `ilium_send_text`, `ilium_type_text`, `ilium_press_key`, `ilium_queue_prompt`, `ilium_create_agent`, `ilium_read_settings`, `ilium_board_delete_card`, `ilium_search_query`, `ilium_search_open_result`) follow the monolith control/tools.rs and must be confirmed against the manual.
- crate `ilium-plugin-testkit`, `FakeHost::onboarding_demo(&mut self, step: &str) -> &mut FakeDemo` with `tools(&self) -> Vec<String>`, `call(&mut self, call_id: &str, tool: &str, args_json: &str) -> Result<String, PluginError>` (a repeated call id returns the first result without re-running; limits 1024 calls and 1024 argument bytes) and `bulb(&self) -> Option<bool>` (F-053; the lightbulb demo tool is `set_lightbulb` per API_GAPS.md of the features part).
