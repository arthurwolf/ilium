# API gaps found by the port twins (plugins/core/cost/tests/port)

- ilium-plugin-core-cost (CostClient, CostServer): a `message` event on channel `port.<op>` with a JSON payload is answered by exactly one `message` intent whose payload is the JSON reply. Ops: `model.*` (price table, levels, burn), `chart.plot`, `chart.resample`, `history.scan`, `history.last-line-containing`, `history.request-scans`, `value-cost.edit`, `overlay.*`, `settings.*`, `settings-ui.*`, `app.cost-row`, `filesystem.ordered-config-writes`, `tree-ui.render-order`, `ui.late-layers-source-transparent`, `ipc.reserve-event-storage`, `reset.*`, `stats.*`, `timeline.*`, `store.*`, `popover.*`, `stats-ui.*`, `tracker.*`, `prep.*`. Required by every PORT requirement of the cost plugin: the manual defines no surface for the pure-logic domains the original tests cover, so the twins assume this request/reply convention. NaN travels as JSON null and enums are snake_case.
- ilium-plugin-sdk FakeHost: `kernel_settings()`, `agent()` and `published_topics()` accessors are missing. Required by the settings, overlay and tracker twins to observe plugin state without a message round trip.
- ilium-plugin-core-cost: no `Views` export and no panel contribution is declared, so the popover and statistics UI twins (`popover.*`, `stats-ui.*`) cannot observe rendering directly and rely on a text/geometry reply. Required by PORT session_stats_popover and session_stats_ui.
- ilium-plugin-sdk host: no file-level transcript/JSONL ingest channel (offset-resumable read of a path with a per-pass byte bound and cancellation). Required by PORT session_stats, session_stats_store and cost_tracker/preparation; the twins carry only the key values and a fixture description, not the files.
- ilium-plugin-core-cost: twins of tests that used tempdirs, a real PTY, blocked worker threads or UI mouse events (`prep.*`, `store.*`, `popover.*`, `reset.fetch-on-io-worker`) answer scenario summaries only. Required by PORT cost_tracker/preparation, session_stats_store, session_stats_popover and reset_planning.
- plugins/core/cost/Cargo.toml: the `tests/port/main.rs` target needs a `[[test]] name = "port"` entry if auto-discovery of subdirectory tests does not apply. Required so the twins are compiled.
