- ilium-client: module `ilium_client::plugin_host::screens_rig` (test-support, no feature gate), why: no client rig draws the Plugins tab, Capabilities tab, Extensions tab, recovery page, review/trust/replace dialogs, footer and notices into a screen buffer and feeds keys back (USR-014..USR-214).
