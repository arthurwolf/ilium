# API gaps of the render lane, client side (part 1)

- ilium-client: dev-dependency `ilium-plugin-api = { version = "0.1.1", path = "../ilium-plugin-api" }` (WID-005..007, the tests name `Constraint`; why: the client does not re-export it).
- ilium-client: module `ilium_client::plugin_host::widget_rig` (feature-free, test-support), why: no client rig renders a ui-tree into a screen buffer and feeds input back.
- ilium-client: `pub fn solve_row(width: u16, constraints: &[Constraint]) -> Vec<u16>` (WID-006, WID-007, why: layout solver order and clamping have no entry point).
- ilium-client: `pub fn install_with_widget(widget: &str, listed_in_unstable: bool) -> Result<(), String>` (WID-022, why: manifest.unstable-missing for calendar).
- ilium-client: `pub struct WidgetRig;` with `pub fn new(columns: u16, rows: u16) -> WidgetRig`, `pub fn grant(self, name: &str) -> WidgetRig`, `pub fn capability(self, name: &str, on: bool) -> WidgetRig` (WID-013, WID-024).
- ilium-client: `WidgetRig` drawing: `pub fn screen_text(&self) -> String`, `pub fn screen_rows(&self) -> Vec<String>`, `pub fn frame_text(&self) -> String`, `pub fn paint_frame_ms(&mut self) -> u64`, `pub fn begin_frame(&mut self)`, `pub fn end_frame(&mut self)`, `pub fn block_plugin(&mut self, blocked: bool)`, `pub fn advance_ms(&mut self, ms: u64)` (HST-250, HST-257).
- ilium-client: `WidgetRig` showing: `show_button(&mut self, key: &str, label: &str)`, `show_button_row`, `show_button_with_tooltip(key, label, tooltip: &str)`, `show_toggle(key, label, value: bool)`, `show_confirm(key, label)`, `show_text_input(key)`, `show_text_area(key: &str, debounce_ms: Option<u32>)`, `show_text_area_with_initial(key, debounce_ms, initial: &str)`, `show_paragraph(text: &str)`, `show_paragraph_with_action_span(key, text)`, `show_gauge(ratio: f64)`, `show_progress_row(percent: f32)`, `show_chart(values: &[f64])`, `show_calendar(year: u32, month: u8)`, `show_image(asset: &str)`, `show_image_bytes(&[u8])`, `show_image_of_size(bytes: usize)`, `show_code_view_foreign_buffer()`, `show_code_view_missing_buffer()`, `show_terminal_view_pane(pane: u64)`, `show_list_of(key, items: u32)`, `show_layout(&mut self, children: usize, constraints: &[Constraint]) -> Result<(), String>`, `show_layout_with_popup()`, `show_modal_popup(key)`, `show_popup_over_button(key, under)`, `show_pointer_only_node(key, label)`, `show_escape_stack()`, `show_focus_order_tree(&[(&str, Option<i16>)])`, `queue_tree_paragraph(text)` (WID-005..029).
- ilium-client: `WidgetRig` input and state: `click_text(&mut self, text: &str)`, `hover_text`, `type_text`, `press_escape()`, `press_escape_and_report_layer() -> Option<&'static str>`, `press_tab()`, `scroll_list(key, rows: u32)`, `unfocus_view()`, `focused_key() -> Option<String>`, `plugin_requests_focus(key) -> bool`, `open_popup(id) -> Result<(), String>`, `open_popup_in_view(view: u32, id) -> Result<(), String>`, `close_popup(id) -> Result<(), String>`, `closed_events() -> Vec<String>`, `actions() -> Vec<UiActionRecord>`, `actions_for_other_views() -> usize`, `layout_child_widths() -> Vec<u16>`, `gauge_filled_cells() -> u16`, `tooltip_text() -> Option<String>` (WID-008..012, WID-018, WID-025..027).
- ilium-client: `pub struct UiActionRecord { pub key: String, pub action_id: String, pub value: String }` with `pub fn field_count(&self) -> usize` (WID-027, why: the ui-action event has five fields).
