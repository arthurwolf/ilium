# Bundled font

`CascadiaCode-Regular.otf` — Cascadia Code, © Microsoft Corporation, licensed
under the SIL Open Font License 1.1 (permits embedding/redistribution as part
of software). Sourced from https://github.com/microsoft/cascadia-code.
Used by `ilium`'s markdown header rasterizer (`ilium/src/markdown/raster.rs`)
so rendered headers look consistent across terminals regardless of the host
terminal's configured font.
